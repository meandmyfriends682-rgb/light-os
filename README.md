LIGHT OS

A tiny, lightweight Linux distribution.

Light OS is an experimental minimal Linux operating system powered by the Linux kernel and BusyBox.

The goal of Light OS is to provide a small, simple and lightweight Linux environment.

Features

- Lightweight Linux system
- Linux kernel
- BusyBox 1.37
- x86_64 architecture
- RAM-based root filesystem
- UEFI boot support
- Minimal command-line interface

System Requirements

- 64-bit x86 processor
- 256 MB RAM recommended
- UEFI-compatible virtual machine or computer

Running Light OS

Light OS can be tested using QEMU.

1. Download the latest release.
2. Extract the downloaded archive if necessary.
3. Start Light OS using the provided launcher.
4. Wait for the Linux shell to appear.

Commands

Command| Description
"help-light"| Display Light OS help
"light-info"| Display system information
"uname -a"| Display kernel information
"free"| Display memory information
"ls /"| List root directory

Project Principles

- Keep Light OS lightweight.
- Preserve the Mini edition.
- Make the desktop optional.
- Avoid unnecessary preinstalled software.
- Keep the ISO sizes as small as practical.
- Prioritize stability and reliability.

Project goal: A lightweight, practical Linux distribution with both a minimal terminal edition and an optional graphical desktop.
